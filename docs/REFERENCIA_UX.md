# Referência de experiência

O fluxo publicado espelha a área de disciplinas do AVA oficial: **Minhas disciplinas → disciplina → bimestre → semana → recurso**.

A superfície mantém apenas o que serve a esse percurso: barra superior fixa, catálogo de disciplinas, cartões de bimestre, linha de semanas, trilha de navegação, sumário lateral contextual e blocos expansíveis de aula. Calendário, notificações, e-mail, perfil, acesso rápido, banners e funções institucionais não fazem parte do portal.

As páginas de recurso preservam a hierarquia visual do AVA e exibem unicamente `A resposta ainda não foi divulgada.` como conteúdo indisponível. O botão de tema do Eclesiastes é a única ação adicional mantida.
