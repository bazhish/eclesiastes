As respostas reais vêm dos Markdown locais em `C:\Users\MAX\Desktop\Gabarito`, são exibidas em blocos copiáveis e não devem ser reescritas durante a migração. Toda mudança de conteúdo deve ser rastreável no índice gerado e passar por `npm run verify` antes de publicação.
