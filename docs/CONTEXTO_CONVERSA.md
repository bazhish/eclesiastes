# Estado de manutenção

O projeto se chama **Eclesiastes** e publica a estrutura do 3º bimestre de Desenvolvimento de Sistemas. A pasta externa `gabarito` só deve ser usada novamente quando houver conteúdo novo autorizado; ela não deve ser alterada pelo repositório.

O acervo tem 7 matérias, 47 semanas, 118 roteiros práticos e 71 blocos “Pausa e Responda”. As respostas antigas foram removidas, cada página exibe o aviso “Essa resposta ainda não divulgada”, e não há arquivos textuais incorporados. Toda mudança de conteúdo deve ser rastreável no índice gerado e passar por `npm run verify` antes de publicação.
