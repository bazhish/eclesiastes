# Estado de manutenção

O projeto se chama **Eclesiastes** e publica o 3º bimestre de Desenvolvimento de Sistemas. A pasta externa `gabarito` é a fonte de verdade atual; ela não deve ser alterada pelo repositório.

O acervo tem 7 matérias, 47 semanas, 118 roteiros práticos, 71 blocos “Pausa e Responda”, 141 respostas e 72 diretórios de artefatos. Toda mudança de conteúdo deve ser rastreável no índice gerado e passar por `npm run verify` antes de publicação.
